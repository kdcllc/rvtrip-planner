Pitfall: changing the shape of `useVehicleSettingsContext` breaks four app-level test files that mock it by hand — src/app/App.test.tsx, src/app/AuthenticatedApp.sync.test.tsx, src/__tests__/auth-integration.test.tsx, src/__tests__/landing-admin-flow.test.tsx. They also mock `useVehicleProfileSync` by name.

Seen in goal multi-vehicle-garage (2026-11-27): the planner's consumer search excluded `*.test.*` and missed them; the goal evaluator caught it before execution. Fix was to add `garage`/`debouncedGarage` to each mock.

How to avoid: when a React context or hook changes shape, search including test files (`rg 'vi.mock\(.*useVehicleSettings'`) and put the mocking test files in the owning task's writes.
