SWA deploy pitfalls with azd + SWA CLI 2.x: (1) SWA CLI defaults the deploy env to `preview` — set `"env": "production"` in swa-cli.config.json or deploys never reach the live site. (2) The upload SAS lives ~2 minutes; zipping `api/` with dev node_modules (~29 MB) expired it (403 AuthenticationFailed). Bundle the Functions API with esbuild into a small folder (here `api/scripts`, ~0.65 MB zip). (3) Free-tier Azure SQL resume takes ~45 s; with a 10 s connectionTimeout the error is ConnectionError ETIMEOUT, not 40613 — map it to 503 + Retry-After.
