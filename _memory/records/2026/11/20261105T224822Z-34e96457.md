Vitest flake pitfall: `vi.mock('../shared/db', async () => ({ ...(await vi.importActual('../shared/db')), ... }))` on a module that is circularly imported (http.ts/session.ts) intermittently yields a mock missing exports under CPU load (~1/17 runs: "No X export is defined on the mock"). Use synchronous self-contained mock factories. Also: `beforeEach(() => mock.mockReset())` returns the mock, which vitest treats as a teardown — use braces.
