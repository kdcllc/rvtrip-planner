Goal rv-profile-fuel-history — outcome: shipped to PR #32 (branch feat/timeline-gantt-display, 2026-11-26), fifth goal on that branch.

What shipped: an RV profile per account (name, fuel type gasoline/diesel, MPG, tank) in dbo.vehicle_profiles via GET/PUT /api/vehicle-profile, synced by src/hooks/useVehicleProfileSync.ts (load after sign-in, one-time copy of the browser MPG, debounced save, retry after a failed load, server wins). Weekly retail fuel prices from the EIA API v2 (petroleum/pri/gnd; EPMR gasoline, EPD2D diesel) cached in dbo.fuel_price_weekly and served by GET /api/fuel-prices with staleness rules (no rows; >24h old and window reaches the newest week; coverage gaps in the window; an in-memory series-start map). Each stop's fuel cost uses its area (src/domain/gas/fuelArea.ts: state series where EIA has one, else PADD; diesel has a state series only for CA), the profile's fuel type and its arrival week (src/domain/gas/travelPrices.ts); dates after the newest week use the latest; no data falls back to the FuelEconomy.gov national average. Summary shows "Fuel price basis". Optional EIA_API_KEY app setting via Bicep (added only when non-empty) and the provision workflow's repository secret.

Key decisions: one profile per account; DB cache rather than per-request EIA calls; key optional with national-average fallback; timeline-driven behaviour unchanged.
