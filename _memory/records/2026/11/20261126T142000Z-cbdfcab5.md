Pitfall: running the ui-ux-pro-max skill's Python search script rewrites tracked bytecode files under .agents/skills/ui-ux-pro-max/scripts/__pycache__/*.pyc, which then show as modified outside every task fence.

Seen in goal timeline-gantt-display (2026-11-26): an evaluator ran the search script three times and three .pyc files appeared in `git status`; detected by the orchestrator's post-spawn fence check and restored with `git checkout -- .agents/skills/ui-ux-pro-max/scripts/__pycache__`.

How to avoid: in any context package that lets a subagent run that script, add the rule "set PYTHONDONTWRITEBYTECODE=1 (or run python3 -B) before running skill scripts". Longer term, untrack the __pycache__ directories and ignore them.
