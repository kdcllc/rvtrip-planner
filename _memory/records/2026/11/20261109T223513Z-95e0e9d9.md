Decision (goal custom-email-domain, 2026-11-09): for an ACS custom email domain whose DNS zone lives in Azure DNS in another RG (moedim.dev in moedim-rg), bicep owns the DNS verification records through a cross-RG module, rather than having them added by hand or by an additive az CLI hook.

Alternatives considered:
- Manual records documented in DEPLOYMENT.md.
- Skipping the DNS module in CI (a MANAGE_EMAIL_DNS flag).
- An additive `az network dns record-set txt add-record` in the hook.

Rationale:
- Keeps it declarative and identical in CI and local runs.
- The user chose to grant the CI identity DNS Zone Contributor on moedim-rg.

Consequences:
- An Azure DNS TXT record set is a single resource, so the deployment fully owns the apex TXT. Every value to keep must be listed in main.bicep's existingApexTxtValues default, or it is removed on the next provision.
- Linking the domain is gated by the useCustomEmailDomain toggle until verification completes.
