Pitfall: ripgrep skips hidden directories by default, so consumer searches like `rg -n 'ADMIN_EMAILS' .` silently miss .github/workflows/. Detected in goal sync-and-ci-migrations when the Phase 3 evaluator cited .github/workflows/azure-provision.yml consumers absent from the planner's search output. Avoid: always pass --hidden with --glob '!.git/**' (and exclude _memory, node_modules, .claude) for repo-wide trace searches, or list .github explicitly.
