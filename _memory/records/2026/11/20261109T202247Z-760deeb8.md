Goal admin-invite-someone (2026-11-09): admins can invite any address from the Access requests panel and see the invite link once.

Shipped:
- `POST /api/manage/invites` (handler `createInvite`, admin + CSRF): validates email (same rules as invite-requests), name defaults to the email local part, 409 when a users row or a registered request exists, reuses existing requests, inserts otherwise (2627/2601 race → re-select).
- `createInvite` and `sendInvite` share `issueAndSend`; both return `InviteSentResponse { request, inviteLink, emailSent }`. Email failure (incl. ACS not configured) no longer revokes the code: 200 with `emailSent: false`.
- Client `createInvite` / `InviteSentResult` (kind 'sent'); `email-failed` kind removed.
- Panel: Invite someone form + shared one-time link panel (Copy / Done), link only in React state.
- Routes live under `/api/manage` because the deployed SWA Functions host 404s every `/api/admin*` path.

Open follow-ups: B1–B8 in the goal's follow-ups.md (null name accepted, Copy fallback untested, focus after error, unused revokeInviteCode, APP_BASE_URL misconfig orphan code, retire shared INVITE_CODE).
