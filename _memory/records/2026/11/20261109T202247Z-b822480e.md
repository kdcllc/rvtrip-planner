Pitfall: in this environment `rg` is a shell function, not a binary. Commands run through Python `subprocess(shell=True)` (or any non-interactive sh) find no `rg` and silently produce empty output, which reads as "0 hits".

Seen in goal admin-invite-someone: goal.md searches S4/S5 were first recorded as 0 hits; S4 really had 5. trace-lint still passed (format-only).

How to avoid: run searches in the Bash tool shell itself and redirect to files, then embed; or call the real ripgrep path explicitly. Treat an unexpected 0-hit search as suspect and re-run it directly.
