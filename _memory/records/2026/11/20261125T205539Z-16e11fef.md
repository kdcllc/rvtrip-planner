Goal app-versioning-and-cleanup — outcome: shipped on branch feat/app-version-and-cleanup (working tree at archive time; PR pending user approval).

What shipped: app version 1.0.0 = package.json semver + short git commit + build time, injected by vite.config.ts (GITHUB_SHA, else git rev-parse, else "unknown"); every build emits version.json, served by Static Web Apps with Cache-Control: no-store. src/hooks/useVersionCheck.ts polls /version.json on mount, every 5 minutes and on focus/visibility (off in dev); UpdateBanner offers Reload, never forces it. src/services/version/bootstrap.ts is the first import in src/main.tsx and clears localStorage keys matching tripPlanner.*.cache.* once per version+commit, keeping trips, vehicle settings and theme. VersionLabel shows v<version> (<commit>) on the landing footer and in the signed-in app. Google removal: Google Routes provider and apiKey path, googleMaps.ts and the "Open in Google Maps" buttons, Google Fonts (now @fontsource-variable/fraunces and nunito-sans 5.3.0, CSP font-src 'self'). Dead-code sweep removed WeatherPanel, setGeocodingProvider, AuthState, web ApiErrorCode/TripConflictResponse/API_ERROR_CODES, updateTripTimestamp, calculateTripTotalCost, calculateTripTotalFuelCost, and in the API LogoutRequest, ApiErrorCode, API_ERROR_CODES, getConfig, AppConfig, revokeInviteCode, serializeCookie.

Key decisions: no service worker; banner instead of auto reload; caches-only reset; google-site-verification TXT in infra/main.bicep kept; Google secret-scan patterns in repo-hygiene.test.ts kept; selection controls in TripForm kept because they drive export and print.
