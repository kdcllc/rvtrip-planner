Pitfall: implementer/test-writer subagents that run Prettier with default settings reformat whole files to double quotes + semicolons. This repo has no Prettier config and uses single quotes, no semicolons (TS/TSX).

Seen in goal admin-invite-someone task 03: diff ballooned to +258/−104 for ~60 logical lines; needed a style fix cycle.

How to avoid: in every implement/test context package say "do not run Prettier with defaults; if formatting, use `--no-semi --single-quote --print-width 100 --trailing-comma es5`". Orchestrator check after each spawn: `git diff -- <file> | grep -c '^+.*;\s*$'` on TS files (CSS and JSX attribute quotes are expected).
